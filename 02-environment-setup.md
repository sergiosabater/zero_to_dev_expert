## 🏗️ Building Your Workshop
In the previous chapter, we sharpened the axe. Today, we build the workshop. To be a **DevExpert**, you don't need the most expensive computer in the world, but you do need the right tools and the knowledge of how to use them.

We are going to set up three pillars:
1.  **The Editor:** Where you write the magic (VS Code).
2.  **The Terminal:** Where you give direct orders to your system.
3.  **Git:** Your time machine (so you never lose progress).

---

## 🖥️ Part 1: Visual Studio Code (The Industry Standard)
There are many editors, but **VS Code** is the king. It’s lightweight, powerful, and has the best AI integration.

### 📥 Installation
* Download it at: [code.visualstudio.com](https://code.visualstudio.com/)
* **Pro Tip:** During installation on Windows, check the boxes that say **"Add to PATH"** and **"Open with Code"**. It will save you many clicks in the future.

### 🚀 AI-First Extensions (Your Competitive Edge)
Go to the Extensions icon (the squares on the left) and install these:
* **GitHub Copilot / Cursor / Claude Dev:** Your AI pair programmer.
* **Prettier:** To keep your code clean and professional automatically.
* **Error Lens:** So errors don't hide; it highlights them directly in your line of code.
* **Material Icon Theme:** Because looking cool helps you code better.

## 🐚 Part 2: The Terminal (Don't Panic!)
The terminal (or console) is that "black box" you see in hacker movies. It doesn’t bite. It’s simply a way to talk to your PC without using a mouse.

### Survival Commands 📜
Open your terminal (in VS Code: `Ctrl + \`` or `Terminal > New Terminal`) and try these commands:

| Command | What it does |
| :--- | :--- |
| `pwd` | "Where am I?" (Shows your current folder) |
| `ls` (or `dir` on Windows) | "Show me what's here" (Lists files) |
| `cd folder-name` | "Go into that folder" |
| `mkdir new-folder` | "Create a new folder" |

> **Survival Note:** If you feel lost, type `cd ..` to go back one level. It’s like the "back" button on your browser.

## 🕒 Part 3: Git & GitHub (Your Time Machine)
Imagine you are playing a difficult video game. What do you do before a boss fight? **You save the game.**
**Git** is the system for "saving your game" in code.

### 1. Install Git
* Download it at: [git-scm.com](https://git-scm.com/)

### 2. Configure Your Identity
Open your terminal and type these two commands with your info (this tells Git who made the changes):

```bash
git config --global user.name "Your Real Name"
git config --global user.email "your@email.com"
```

### 3. Your GitHub Account
Create an account at [GitHub.com](https://github.com). This is your portfolio, your CV, and your social network as a developer.
