## 🐚 Part 2 · The Terminal  
### *Don’t Panic.*

The terminal (or console) is that *black box* you see in hacker movies.  
Good news: **it doesn’t bite** 🐍

It’s simply a faster, more precise way to talk to your computer.

### 📜 Survival Commands

Open the terminal in VS Code:

- **Shortcut:** `Ctrl + \``  
- Or: `Terminal → New Terminal`

Try these commands 👇

| Command | Meaning |
|------|------|
| `pwd` | 📍 Where am I? (current folder) |
| `ls` / `dir` | 📂 What’s here? |
| `cd folder-name` | ➡️ Enter a folder |
| `mkdir new-folder` | 🆕 Create a folder |

> 🧭 **Survival Tip:**  
> Feeling lost?  
>  
> ```bash
> cd ..
> ```  
>  
> It’s the terminal’s **Back button**.

## 🕒 Part 3 · Git & GitHub  
### *Your Personal Time Machine*

Imagine a hard video game 🎮  
Before a boss fight… you **save the game**.

**Git = Save Game for Developers**

---

### 1️⃣ Install Git

🔗 Download from: **https://git-scm.com**

---

### 2️⃣ Configure Your Identity

Tell Git who you are:

```bash
git config --global user.name "Your Real Name"
git config --global user.email "your@email.com"
```

This info will appear in every commit you make.
