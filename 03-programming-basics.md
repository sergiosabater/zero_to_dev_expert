## 🏗️ What Is Programming, Really?

Programming is **telling a computer what to do**, step by step,  
in a language it understands.

At its core, programming is:
- 🧩 Problem solving
- 🧠 Logical thinking
- 📐 Breaking big ideas into small, clear steps

> 💡 **Good programmers don’t memorize code — they understand logic.**

---

## 📦 Part 1 · Variables  
### *Giving Names to Things*

A **variable** is a labeled box where you store information.

Think of it like this:

> 📦 A box with a name → containing a value

### 🐍 Python Example

```python
age = 30
name = "Sergio"
isDeveloper = True
🟨 JavaScript Example
javascript
Copiar código
let age = 30;
let name = "Sergio";
let isDeveloper = true;
🧠 Key Idea
Variables store data

You can change their values

Names should be clear and meaningful

🔀 Part 2 · Logic & Conditions
Teaching Computers to Decide
Computers are fast…
but they are not smart.

They only understand true or false.

🧪 Example: Decision Making
Python
python
Copiar código
age = 18

if age >= 18:
    print("Access granted")
else:
    print("Access denied")
JavaScript
javascript
Copiar código
let age = 18;

if (age >= 18) {
  console.log("Access granted");
} else {
  console.log("Access denied");
}
🧠 Mental Model
IF something is true
→ DO this
ELSE
→ DO that

This is the foundation of all logic in software.

🔁 Part 3 · Repetition (Loops)
Doing Things More Than Once
When you want to repeat an action, you use a loop.

🔄 Example: Counting
Python
python
Copiar código
for i in range(5):
    print(i)
JavaScript
javascript
Copiar código
for (let i = 0; i < 5; i++) {
  console.log(i);
}
Instead of writing the same code 5 times,
you teach the computer to repeat it.

🧠 Part 4 · Thinking Like a Programmer
Before writing code, ask yourself:

❓ What is the problem?

📥 What input do I have?

📤 What output do I want?

🧩 What steps are needed?

✨ If you can explain it in plain language, you can code it.

🤖 AI Tip · Learn Faster, Not Lazier
Use AI to:

Ask for explanations

Generate examples

Clarify errors

❌ Don’t:

Skip understanding

🏆 Rule:
AI accelerates learning — it does not replace thinking.
